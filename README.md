# Modular ESP Word Clock Hardware Platform

**Build a professional Word Clock without soldering hundreds of LEDs.**

This is a modular, open-source hardware platform designed to make Word Clocks much easier to build, customize, and replicate.

Traditional Word Clock projects usually require:
- Soldering individual LED beads or cutting LED strips
- Designing and manufacturing the faceplate silkscreen yourself
- Solving light leakage and alignment issues

This project solves those problems with a clean **three-layer sandwich design**.

---

### Key Features

- **Pre-assembled PCBA** with LED matrix already mounted (no LED soldering required)
- **Modular sandwich structure**:
  1. Main PCBA (LEDs on front + control electronics on back)
  2. Light separator plate (prevents light bleeding)
  3. Silkscreen acrylic faceplate (easy to customize for different languages)
- Fixed with standard M3 screws and nuts
- Type-C power supply
- Compatible with most existing ESP Word Clock firmware
- Fully open-source design files (PCB + mechanical)

Just screw the three layers together and power it up.

---

### Hardware Overview

| Layer              | Description                          |
|--------------------|--------------------------------------|
| Main PCBA          | Double-sided board with LED matrix + ESP control circuit |
| Separator Plate    | Blocks light between letters         |
| Faceplate          | Silkscreen acrylic with letters      |

---

### Quick Assembly

1. Place the separator plate on the PCBA
2. Put the silkscreen acrylic on top
3. Secure with M3 screws and nuts
4. Connect Type-C power
5. Flash your preferred Word Clock firmware
